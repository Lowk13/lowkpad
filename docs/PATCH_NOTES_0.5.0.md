# LowkPad 0.5.0

19 de septiembre de 2026.

- **Elige cómo sujetas el iPhone:** Mesa, Mano derecha o Mano izquierda. El selector cambia la posición de los controles sin intercambiar clic izquierdo y derecho.
- **Tres alturas:** Compacta, Media y Amplia para ajustar el alcance del pulgar. La pantalla se adapta también al uso horizontal.
- **Clic y Derecho a mano:** botones visibles que puedes mantener pulsados mientras mueves el cursor.
- **Arrastrar / Soltar:** mantén una ventana o una selección agarrada aunque levantes el pulgar para recolocarlo. El arrastre se libera al salir del contexto de control.
- **Precisión:** activa un movimiento más lento, ×0,35, para apuntar a objetivos pequeños; vuelve a tocar para recuperar la velocidad habitual.
- **Scroll accesible:** franja lateral adaptada al lado elegido y con ancho de 44–64 puntos según el espacio. Se mantiene el scroll con dos dedos, sin inercia añadida.
- **Gestos más robustos:** mejor separación entre clic, desplazamiento y arrastre; los botones visibles y los gestos coordinan su estado para evitar soltar un arrastre que sigue pulsado.
- **Golpecito opcional:** empieza apagado en instalaciones nuevas para evitar clics al recolocar el teléfono. Si ya lo tenías configurado, se respeta tu preferencia.

Se conservan la barra inferior desplazable, multimedia, portapapeles, teclado en tiempo real y atajos, incluidos **Win + Mayús + ←/→** para mover ventanas entre monitores.

Compatible con el **host 0.4.0**: usa la **misma IP y clave**. Las posiciones y el factor de precisión son opciones iniciales para comparar en tu iPhone; la comodidad y la respuesta física dependen del agarre y de la red.
